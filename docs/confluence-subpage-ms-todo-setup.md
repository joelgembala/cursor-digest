# Microsoft To Do setup

The maintained instructions are in [Connected setup](setup.md#service-access).

The adapter uses Microsoft device-code authorization and stores its token cache locally in an ignored file. Token refresh depends on provider and tenant policy; reauthorization may be required. Running the installer does not export environment variables into an existing terminal session. Follow the manual environment-loading step in the maintained guide before running setup commands.

This filename is retained so earlier links continue to work.
